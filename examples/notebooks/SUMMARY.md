## 🎯 Что демонстрируется

### Working Memory (Redis)
- ✅ Создание сессии
- ✅ Сохранение сообщений
- ✅ Обновление контекста
- ✅ Просмотр истории

### Episodic Memory (MongoDB)
- ✅ Создание эпизода
- ✅ Добавление траектории (4 шага)
- ✅ Просмотр полного эпизода
- ✅ Метрики качества (успех, важность, удовлетворенность)

### Semantic Memory (MongoDB + Qdrant)
- ✅ Создание знаний
- ✅ Разные источники (INFERRED, USER_PROVIDED)
- ✅ Temporal scope и half-life
- ✅ Теги для поиска

### OpenAI Integration
- ✅ Генерация ответов через GPT-4o-mini
- ✅ Использование контекста из всех типов памяти
- ✅ Автоматическое сохранение взаимодействий
- ✅ Создание эпизодов из диалога

### Трансформация данных
- ✅ Диалог → Эпизод
- ✅ Эпизод → Знание
- ✅ Знание → Контекст для LLM
- ✅ Визуализация всех этапов

## 💡 Ключевые примеры кода

### 1. Создание сессии
```python
await working_memory.create_session(
    session_id=session_id,
    agent_id=agent_id,
    initial_context={...},
    ttl_seconds=7200
)
```

### 2. Создание эпизода с траекторией
```python
await episodic_memory.create_episode(
    episode_id=episode_id,
    episode_type=EpisodeType.INTERACTION,
    agent_id=agent_id,
    success=True,
    importance=0.85,
    tags=[...]
)

await episodic_memory.append_to_trajectory(
    episode_id=episode_id,
    step_data={...}
)
```

### 3. Извлечение знания
```python
await semantic_memory.create_knowledge(
    knowledge_id=knowledge_id,
    knowledge="...",
    source=SourceType.INFERRED,
    confidence=0.9,
    agent_id=agent_id
)
```

### 4. Генерация ответа с памятью
```python
# Получение контекста из всех типов памяти
messages_history = await working_memory.get_messages(...)
knowledge = await semantic_memory.query_knowledge(...)
episodes = await episodic_memory.query_episodes(...)

# Отправка в OpenAI
response = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[...],
    temperature=0.7
)
```

### Быстрый старт
