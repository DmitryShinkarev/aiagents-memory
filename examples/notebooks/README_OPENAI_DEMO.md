# OpenAI Memory Demo - Руководство

Этот ноутбук (`openai_memory_demo.ipynb`) демонстрирует полную интеграцию Memory Agents с OpenAI API.

## 🎯 Что демонстрирует ноутбук

### 1. Основные типы памяти
- **Working Memory** (Redis) - кратковременная память для текущего диалога
- **Episodic Memory** (MongoDB) - эпизоды взаимодействий с траекториями
- **Semantic Memory** (MongoDB + Qdrant) - долговременные знания

### 2. Интеграция с OpenAI
- Генерация ответов через GPT-4o-mini
- Использование контекста из всех типов памяти
- Автоматическое сохранение всех взаимодействий

### 3. Трансформация данных
- Как диалог превращается в эпизод
- Как эпизоды превращаются в знания
- Как знания используются для улучшения ответов

## 📋 Требования

### Системные требования
```bash
# Docker с запущенными сервисами
docker-compose up -d

# Или убедитесь, что запущены:
# - Redis (порт 6379)
# - MongoDB (порт 27017)
# - Qdrant (порт 6333)
# - PostgreSQL (порт 5432)
```

### Python пакеты
```bash
pip install openai python-dotenv jupyter ipywidgets
```

### OpenAI API Key
Получите ключ на https://platform.openai.com/api-keys

Создайте файл `.env` в корне проекта:
```bash
OPENAI_API_KEY=your_api_key_here
```

## 🔍 Важные примечания

### Без OpenAI API
Ноутбук может работать и без OpenAI API, но с ограниченной функциональностью:
- Базовые операции с памятью работают
- Генерация ответов через LLM недоступна
- Используются заранее заготовленные ответы

### Стоимость OpenAI
GPT-4o-mini очень экономичен:
- ~$0.15 за 1M входных токенов
- ~$0.60 за 1M выходных токенов
- Демо использует ~1000-2000 токенов (несколько центов)

### Персистентность данных
Все данные сохраняются в базах данных:
- **Working Memory**: TTL 2 часа (автоматически удаляется)
- **Episodic Memory**: Хранится постоянно
- **Semantic Memory**: Хранится постоянно

## 🛠️ Устранение проблем

### Ошибка подключения к сервисам
```bash
# Убедитесь, что Docker запущен
docker ps

# Перезапустите сервисы
docker-compose down
docker-compose up -d

# Проверьте логи
docker-compose logs
```

### OpenAI API ошибки
- Проверьте наличие ключа в `.env`
- Проверьте баланс на https://platform.openai.com/account/usage
- Убедитесь, что ключ активен

### Ошибки импорта
```bash
# Переустановите пакеты
pip install --upgrade openai python-dotenv

# Или используйте venv
python -m venv venv
source venv/bin/activate  # Linux/Mac
# или venv\Scripts\activate  # Windows
pip install -r requirements-demo.txt
```
